# Architecture Decision Records

This directory contains the Architecture Decision Records (ADRs) for TITAN Commerce.

ADRs document important engineering decisions, including their context, alternatives, consequences and current status.

## ADR Index

| ADR | Decision | Status |
|---|---|---|
| [ADR-001](0001-modular-monolith.md) | Modular Monolith Architecture | Accepted |
| [ADR-002](0002-postgresql-database.md) | PostgreSQL as Primary Database | Accepted |
| [ADR-003](0003-database-backed-job-queue.md) | Database-backed Job Queue Initially | Accepted |

## ADR Status Definitions

- **Proposed:** Under consideration.
- **Accepted:** Approved for implementation.
- **Superseded:** Replaced by a later decision.
- **Deprecated:** No longer recommended or applicable.

New significant architectural decisions should be documented as separate numbered ADRs.
